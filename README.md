# Umut Biçer - Kişisel Web Sitesi

Tek sayfalık kişisel web sitem. Vize ek puan ödevi için hazırlandı.

- Kullanılan teknolojiler: yalnızca HTML ve CSS
- Yayın: GitHub Pages

## Dosyalar

- `index.html` - sayfanın içeriği
- `style.css` - sayfanın görünümü
- `img/lise.webp`, `img/universite.jpg` - okul logoları

Sayfanın üst kısmındaki ağ kablosu çizimi tamamen CSS ile yapıldı. Teller T568B dizilimindedir.
